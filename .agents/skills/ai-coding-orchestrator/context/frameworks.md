# Problem-Solving Framework Pack

Load only at the relevant decision point.

- OODA: changing incidents/evidence.
- DMAIC: measurable optimization/process improvement.
- 5 Whys/RCA: defects and recurring failures.
- Pre-Mortem: consequential changes, releases, migrations and self-modification.
- First Principles: POCs, architecture and assumption-heavy decisions.
- Six Thinking Hats: multi-perspective review.
- Decision Tree: uncertainty, trade-offs and reversibility.

Routing examples: bug = 5 Whys + OODA; performance = DMAIC; architecture = First Principles + Six Hats; release = Pre-Mortem + Decision Tree; self-improvement = Pre-Mortem + Decision Tree.

Never run all seven mechanically. Record:
`FRAMEWORK | PURPOSE | KEY_FINDINGS | DECISION | EVIDENCE | NEXT`.
