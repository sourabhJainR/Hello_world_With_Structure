# Optional Extensions

Extensions are optional capabilities, never core dependencies. Detect first; use only when installed, enabled, relevant, and permitted. Never install or modify them without explicit approval.

- Graphify: AST, deterministic graph, relationship and impact evidence.
- code-mem / codebase-memory-mcp: persistent code graph, semantic/structural search, call tracing and impact analysis.
- Superpowers: TDD, planning, systematic debugging and execution discipline.
- Ponytail: YAGNI and minimal-change pressure without removing required correctness or verification.
- Caveman: compact output/context handling without lossy compression of source, errors, acceptance criteria, or verification evidence.
- Other Agent Skills/MCP: use only when materially useful.

Precedence: repository/team rules > security/permissions > acceptance criteria > local architecture > verification > orchestrator > optional extensions > model preference.
