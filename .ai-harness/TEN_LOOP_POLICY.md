# Ten-Pass Implementation and Review Policy

This policy defines a bounded review discipline for explicitly requested multi-pass implementation. It does not authorize autonomous looping during ordinary work.

| Pass | Purpose |
| --- | --- |
| 1 | Intake and repository understanding |
| 2 | Requirements and boundary analysis |
| 3 | Architecture and design review |
| 4 | Implementation planning |
| 5 | Focused implementation |
| 6 | Verification and regression analysis |
| 7 | Adversarial review and safety checks |
| 8 | Maintainability, observability, and operational review |
| 9 | Final diff minimization and compatibility review |
| 10 | Release-readiness assessment |

For normal tasks, use the smallest sufficient subset.
