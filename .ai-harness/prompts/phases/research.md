# Capability: Research

Research is an explicit, decision-support capability. Do not implement production changes in this phase.

Investigate only what is relevant to the task. Depending on the selected agent's available tools, inspect:

- repository code and history
- official documentation
- dependency documentation
- standards and specifications
- public issue trackers or known limitations

Clearly separate:

## Facts
Information supported by inspected sources.

## Assumptions
Items that could not be verified.

## Options
Reasonable approaches with trade-offs.

## Recommendation
The preferred direction and why.

## Open questions
Questions that materially affect the implementation.

If external research is unavailable to the selected agent, state that limitation and continue with repository evidence only.
