# POC Skill

Use when the key question is whether an approach can work, not how to productionize it.

## Required behavior

1. Define one falsifiable hypothesis.
2. Keep the experiment narrow and isolated.
3. Reuse production dependencies where useful, but avoid production refactoring.
4. Capture exact commands and observed results.
5. State limitations and what the POC does not prove.
6. Explicitly recommend proceed, change direction, or investigate further.

## Output

- Hypothesis
- Experiment
- Evidence
- Conclusion: supported, rejected, or inconclusive
- Production recommendation
