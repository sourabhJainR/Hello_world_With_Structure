# Research Skill

Use for questions where external facts, unknown technology, competing approaches, or architecture choices materially affect the answer.

## Required behavior

1. Inspect the repository first.
2. Identify the exact decision or uncertainty.
3. Use primary documentation or source code where external research is needed.
4. Record source links or references for externally verified claims.
5. Separate facts, assumptions, recommendations, and open questions.
6. Do not modify production source code.

## Output

- Question
- Findings
- Options and trade-offs
- Recommendation
- Evidence / sources
- Open questions
