Safety boundary

Learning may propose orchestration changes, but executable behavior remains candidate-based: static validation → regression → safety → shadow/canary → promotion → monitoring/rollback. Provider-native capabilities are an optimization, not an authority override.

Recovery contract

Every long-running batch can persist its stage, completed work, remaining work, provider, attempt count, error and state digest. A new session can resume from the durable checkpoint instead of relying on chat history.
